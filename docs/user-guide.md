# PingClash 使用手册

本文对应当前开发版 `0.1.2-preview.5`。操作说明、参数含义和排查方法放在本文；应用界面只保留操作名称、状态、必要错误及安全确认。已发布的旧版 APK 不会随本文自动更新。

## 1. 第一次使用

1. 安装与你设备兼容的 APK。当前支持 Android 10 及以上，提供 arm64-v8a 与 x86_64。
2. 打开底部的「配置」，通过右下角 `+` 添加订阅，或使用「导入文件」。
3. 在配置列表中点选要使用的配置。
4. 打开「代理」，按订阅原有策略组选择节点；需要时将相应策略组设为主代理。
5. 回到首页，选择「规则」「全局」或「直连」。
6. 轻点挂绳卡片，按 Android 系统弹窗授权 VPN。首次可能同时申请通知权限。
7. 以卡片和通知显示的服务状态判断 VPN 是否建立，再通过网站延迟或诊断检查实际链路。

VPN 连接不要求 root。应用中的终端也不会自动申请 root。

## 2. 首页

### 挂绳卡片

- 轻点：连接或断开；连接过程中可以取消。
- 长按再移动：拖动卡片，松手后回弹。拖动和取消拖动都不会切换 VPN。
- 卡片姿态、翻面和装饰动画不单独证明网络可用；实际连接状态来自服务。
- 3D 组件加载或暂时不可用时，原生连接按钮仍可操作。

### 顶部正计时

计时从本次 VPN 首次建立开始，Wi-Fi / 蜂窝切换和等待重连不会把本次计时归零；主动断开后重置。

离开首页时，计时胶囊会横向展开；点按可打开「返回首页」「断开连接」操作卡片，约 4.5 秒不操作会收起。它是已运行时长，不是倒计时，也没有到点自动断开的含义。计时持续增长不代表网络始终可用。

### 配置和模式

| 模式 | 用途 |
| --- | --- |
| 规则 | 按已启用的原配置规则及自定义规则选择出站。规则不兼容时会阻止启用，并显示错误。 |
| 全局 | 将可代理流量交给当前主代理。 |
| 直连 | 使用直连出站；测试结果应按直连路径理解。 |

当前初始模式为全局。模式或网络参数需要调整时，应先断开 VPN；正在运行或测试时部分操作会锁定。

### 网站延迟

首页根据可用空间显示 2–4 项，默认优先显示 Google、ChatGPT、Gemini、YouTube。点按单项只测试该项，闪电按钮测试当前显示项；「更多」可展开全部目标，再选择单项或「测试全部」。仅打开列表不会发出这些测试请求。

这是经过所选出站的原生 Mihomo URL 测试。即使系统 VPN 没开启，应用仍可单独通过所选节点发出探测，因此不能用这个数字判断其他应用是否已进入 VPN。直连模式显示直连路径。

延迟表示收到 HTTP 响应所用时间；错误页面也可能有响应时间。它不判断账号登录、地区限制、服务解锁或 HTTP 成功状态。Google / YouTube 使用轻量 204 目标，其他目标使用固定公开 HTTPS 地址和 HEAD 请求，不读取响应正文或登录账号。

网站测试最多同时执行 4 项；切换配置、节点或 VPN 会话会取消并清理旧结果，结果约 60 秒后过期。

## 3. 配置与订阅

### 添加订阅

1. 在「配置」点 `+`，选择订阅链接。
2. 粘贴服务商提供的 HTTPS 链接，按需填写名称。
3. 点「下一步」，核对来源主机和 User-Agent。
4. 确认导入，等待下载及解析。
5. 点选需要使用的配置，前往代理页选择节点。

订阅链接本身就是凭据。不要将真实链接、查询参数或令牌贴到公共 Issue、截图和群聊中。输入框默认遮挡链接；主动显示明文时，页面会禁止系统截屏和任务快照。

### 文件与文本

「导入文件」通过 Android 文件选择器读取你明确选择的文件。添加窗口中的本地配置入口可粘贴内容。支持范围包括 Clash YAML / JSON、通用 Base64 节点 URI 列表及已实现的协议子集；不保证所有 Mihomo 扩展都兼容。

当前文本响应上限为 2 MiB，最多 500 个节点。复杂配置还受策略组、规则和加密存储预算限制。二维码扫描与图片识别目前未提供，可通过系统文本粘贴或文件导入。

### `clash://install-config` 链接

网页或其他应用触发安装链接时，PingClash 会先显示来源主机。确认之前不下载；仅接受 HTTPS 订阅。

确认会下载配置及其声明的 HTTPS 提供源。导入后配置保持未启用，必须再到配置页明确点选；不会因首次导入、重启或删除另一份配置而自行激活。

### 配置右上角菜单

- 查看代理：进入此配置的策略组和节点。
- 复制订阅链接：只在你主动点击后复制，按钮短暂变成勾选反馈。系统剪贴板被标记为敏感；应用约 60 秒后尝试清除自己仍持有的那份内容，系统限制或进程结束可能影响清除。
- 更新：重新获取订阅；失败时保留上一份有效配置。
- 详情：查看配额、到期日期、提供源状态、未导入原因，并修改 User-Agent。
- 重命名：只改变本地名称。
- 导出：导出节点、策略组和规则。文件含节点密码等凭据，已离开本机加密保护，应保存到可信位置。导出不包含订阅下载链接或应用偏好。
- 删除：移除本地配置；确认后执行。

详情中的「重新解析本地配置」适合升级应用后重新识别保存的原始定义，无须重新粘贴订阅。

### 配额、有效期和 User-Agent

配额来自订阅服务器的 `subscription-userinfo` 响应头。缺失或无效的数据不会被当成无限配额；日期按设备时区显示。服务商没提供时显示未知。

User-Agent 可在导入核对页或配置详情中修改，下次下载时使用。当前默认值为 `Clash.Meta/PingClash-0.1.0`。只接受 1–256 个可打印 ASCII 字符，不能包含换行。不同 UA 可能让服务商返回不同格式；优先使用其明确提供的 Clash / Mihomo 订阅。

### 远程提供源

当前支持受限的 `type: http` 提供源，下载地址必须是 HTTPS。应用保留订阅原有策略组顺序、成员层级和支持的筛选规则，不按国家或协议自行重组。

提供源更新失败会保留最后一次有效配置。VPN 运行时更新内容不会悄悄替换正在使用的链路；收到更新就绪状态后，重新连接以应用新内容。

当前支持范围、YAML / text 规则来源、刷新间隔以及 file / inline / MRS 等限制，详见 [订阅与提供源说明](subscriptions.md)。来源更新依赖进程存活，Doze 或系统结束进程可能延后刷新。

## 4. 代理与策略组

左右滑动策略组或点上方组名，在组内上下滚动并点选节点。嵌套策略组保留原层级。自动选择、故障转移等组由核心按其规则处理；手动可选范围取决于组类型。

代理页更多菜单可将当前组设为主代理。切换组内成员与切换主代理是两个操作：前者修改该组的选择，后者确定首页连接所使用的主要出站。

无效依赖、缺失成员或循环引用会明确显示为不可用，不会擅自替换成直连。配置中不支持的字段可在配置详情中展开查看；不必公开节点地址、UUID 或密码。

### URL 测速与独立 TCP 指标

- 闪电 / URL：由 Mihomo 核心执行实际代理路径测试。
- TCP：从当前非 VPN 底层网络连接节点入口端口，时间不含 DNS，不发送代理认证、TLS 或 HTTP 内容。
- Hysteria2、TUIC 等 UDP 节点以及策略组不适用独立 TCP，显示 `N/A (UDP)` 或不适用。

批量 URL 测试先展开当前请求的策略组并去重，同一节点每轮只测一次；普通节点优先进入并发池。默认并发 10，上限 16，默认超时 5 秒，可在设置中调整。真实代理链保留原路径，其初始化可能更慢。

组卡片显示已测成员数和可用数量，不把成员汇总伪装成某条组路由的延迟。测试可以取消，结果分批更新；大量失效节点仍需要等待超时预算。

## 5. 设置：按右侧箭头进入详情

设置首页采用分类行。点右侧箭头或整行进入详情，左上角返回或系统返回键回到列表。列表中不再常驻顶部「设置 / 诊断 / 终端」标签栏。

### 外观与语言

可选择中文、英文或跟随系统；深浅色、跟随系统外观、海洋 / 云朵 / 无背景分别设置。

「跟随系统配色」需要 Android 12 或以上。「减少效果」会停用装饰动画，系统动画与无障碍设置也会影响动效。「减少透明度」使用更实的材质。Android 13 以上支持折射玻璃，Android 12 使用模糊回退，更早系统使用不透明回退，旧设备不具备相同折射效果。

外观和语言即时生效；页面中需要保存的其他修改以「保存」按钮状态为准。

### DNS

可选择 DNS over TCP 或 DNS over HTTPS。VPN DNS 地址与加密 DNS 地址分别填写，DoH 应是有效 HTTPS 地址。

应用 DNS 由当前主出站处理，不会仅因某条直连规则而自动改用系统解析器。节点入口及必要的引导解析可能使用底层网络。应用自行使用的 DoH、共享 IP 等场景不能可靠还原域名，必要时使用 IP / 端口规则。

### 网络

| 项目 | 默认值 / 可选范围 |
| --- | --- |
| 自动重连 | 开启 |
| IPv6、UDP | 开启 |
| MTU | 1500；1280–9000 |
| 连接超时 | 10 秒；3–60 秒 |
| UDP 超时 | 60 秒；10–300 秒 |
| 最大连接数 | 256；16–512 |
| 测速超时 | 5000 毫秒；1000–20000 |
| 测速并发 | 10；1–16 |
| 统一延迟 | 开启 |

自定义测试地址会被实际访问，应使用可信的轻量目标。网站延迟、节点 URL 延迟和直连 TCP 不是同一种测量，不宜直接比较不同目标、网络或冷启动条件下的数字。

### 应用与内网

应用分流可选全部应用、排除所选应用或仅代理所选应用；仅代理模式至少选一个有效应用。列表仅查询本机可启动应用，不会上传应用清单，也可手动填写包名。

内网模式可选代理、直连或阻断，涵盖私有 IP、回环及链路本地单播地址，优先于一般出站规则。它不开放局域网监听端口。组播和未指定地址始终阻断。

### 出站规则

规则模式下，可启用原配置规则，并在自定义编辑器添加规则；自定义规则位于原规则之前。支持的基本格式例如：

```text
DOMAIN-SUFFIX,example.com,PROXY
IP-CIDR,192.168.0.0/16,DIRECT,no-resolve
DST-PORT,443,PROXY
NETWORK,udp,REJECT
MATCH,PROXY
```

当前支持 DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、IP-CIDR、IP-CIDR6、DST-PORT、NETWORK、MATCH，以及已实现来源展开后的规则子集。出站可使用 PROXY、DIRECT、REJECT 或配置中有效的节点 / 策略组名。上限 2000 条规则、16 个额外出站；不兼容时阻止启用，不会静默忽略。

编辑规则和查看明文连接目标时会启用截屏保护；返回普通页面后恢复。

### 实时状态、连接与使用情况

实时状态查看上下行速度、曲线、流量、服务状态、内存和连接数。活动连接列表可关闭单条或全部连接。

默认不保留累计使用统计，也不记录活动连接目标。开启累计统计后，只在断开时加密保存字节、时长和会话数；系统强杀可能丢失本次计数。关闭该选项会清除历史累计值。

开启连接目标显示后，仅保留活动连接的 IP / 域名，连接结束或服务停止即清理，不写入诊断报告或日志。

### 控制

可以连接 / 断开、重启 VPN、关闭连接、取消测试，并跳转系统 VPN、通知和电池设置。重置网络设置前需确认；不会替代 Android 的系统授权。

## 6. 连接诊断

从设置列表进入「连接诊断」，或从代理页选择节点后进入诊断。辅助探测可手动填写主机、端口、SNI 和地址族，不要求终端命令。

诊断区分当前网络、入口 DNS、TCP、辅助 TLS 和实际代理请求。UDP 协议会跳过不适用的 TCP / 标准 TLS 辅助步骤；跳过不等于失败。直接辅助探测使用非 VPN 底层网络，实际代理请求通过选定出站。

| 结果 | 可先检查的内容 |
| --- | --- |
| 入口 DNS 失败 | 当前网络、域名及解析结果 |
| TCP 拒绝 | 端口是否正确、服务是否监听 |
| TCP 超时 | 地址、网络路径、服务器响应；单次超时不能证明被拦截 |
| 证书错误 | SNI、证书信任和设备时间 |
| 代理请求失败 | 协议参数、认证、传输方式及服务端状态 |
| 网络变化 | 等网络稳定后重新测试 |

TLS 重置或超时本身不能证明运营商拦截、密码错误或服务器故障。使用报告中的分层证据定位，不必公开原配置。

配置若声明跳过节点证书验证，应用保留该策略并首次提醒；这并不等于已验证服务器身份。订阅下载及 HTTPS 网站测试仍校验证书。请仅使用可信配置。

可预览和导出脱敏 Markdown 报告。分享前仍应人工检查内容；不要附上真实订阅链接、密码、UUID、未脱敏终端输出或配置导出。

## 7. 标准终端

从设置列表进入「终端」。首次需确认 UID 权限提示，再新建 `sh` 会话；最多同时 3 个。支持管道、重定向、交互输入、Ctrl+C、Tab、Esc 和方向键。粘贴前会另行确认。

命令使用本应用的 UID 和权限，可能读取 / 修改应用文件并访问网络。终端不会自动把应用凭据作为环境变量传给命令，也不会自动使用所选代理；其网络路径不能直接代表其他应用的 VPN 路径。

可按设备实际提供的工具使用普通 Android 命令，例如：

```sh
pwd
id
help
toybox
getprop ro.build.version.release
command -v ping
command -v curl
```

`ping`、`curl`、`ip` 等工具是否存在、能否执行，取决于 Android / OEM 系统和该 UID 权限；Permission denied 不等于代理故障。应用没有自定义的 PingClash 命令语言。

终端历史和屏幕内容默认只在会话内存；退到后台会关闭会话。你手动执行文件写入或重定向仍会留下文件。只运行理解且可信的命令，不向公共反馈附上未经检查的输出。

## 8. 后台、重连和系统设置

保持 VPN 通知权限可用。Wi-Fi 与蜂窝切换时，自动重连会尝试使用新的底层网络；不需要每次重新授权，但并不保证 OEM 强制结束服务后能自行复活。

如遇后台停止，检查系统电池优化、后台运行限制和通知权限。最近任务卡片是否显示由系统和当前页面保护状态共同决定，不能单独用卡片判断 VPN 服务是否运行。

Android 的「始终开启 VPN」和「阻止未经过 VPN 的连接」在系统 VPN 设置中配置。后者可能在 VPN 不可用时阻断流量，请先了解其行为。卸载或清除应用数据会清除本地配置。

## 9. 安全保存与反馈

配置与偏好在本机加密保存，应用禁用云备份及迁移，不包含遥测、广告或远程崩溃上报。订阅下载、测速、DNS 和代理连接本身仍会访问相应服务。

本机加密不能保护已经导出、主动复制或被终端命令写出的明文。保持设备锁屏，妥善保管配置导出及订阅凭据。不要把签名密钥或账号密码提交到代码仓库。

反馈问题时提供应用版本、锁定的 Mihomo 版本、Android / 系统版本、复现步骤及检查过的脱敏报告即可；不需要设备编号或账号凭据。「关于」保留版本、核心版本和依赖许可证。

更多限制和已验证范围见 [订阅兼容性](subscriptions.md)、[后台与 VPN](background-vpn.md)、[诊断边界](diagnostics.md) 和 [验证记录](security-testing.md)。
