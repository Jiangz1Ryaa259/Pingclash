## 覆盖的边界

- 原生测速使用固定版本 Mihomo 的 URLTest，不新增本地控制器；真实 AnyTLS/TLS 测试覆盖取消、目标证书拒绝和统一延迟模式隔离。
- 导入解析覆盖类型混淆、旧字段、重复键、嵌套、格式错误、数量/体积限制和固定错误类别。模糊测试只是短时有界运行。
- Android 测试覆盖加密资料篡改、不同 UID 访问限制、敏感窗口、导入、设置、原策略组、并行测速、VPN DNS/TCP 转发和终端生命周期。
- 新增终端测试确认：未接受首次 UID 权限提示时不能创建 shell；接受后才启用新建操作。真实 PTY、管道、交互输入、Ctrl+C、OSC 52 限制及后台关闭继续通过。
- 发行包运行 `run-as` 被系统拒绝。签名证书是项目发布身份，不是第三方安全认证。

## 尚待验证或实现

- 远程 proxy-providers / rule-providers、订阅配额与到期头、自定义下载 UA、深度链接及二维码导入。
- 独立 TCP 与 URL 指标、用户触发的 DNS 预热，以及更完整的已脱敏配置语料库。
- 完整 strings.xml / plurals / locale-config 迁移与 ktlint/detekt；当前仅新增终端提示资源及版本目录。
- 自动 Wi-Fi/蜂窝重连、Quick Settings 磁贴、Android 12–14 物理设备与厂商后台行为；当前丢失底层网络会安全停止，不宣称已自动重连。
- 长期压力、全部原生依赖人工审计、构建供应链、系统漏洞、恶意辅助功能/输入法及 root 环境。

终端具有应用 UID 的文件和网络权限；用户命令可以主动输出或保存其输入的秘密。默认关闭历史文件不等于能阻止用户显式写文件。VPN 停止后的持续断网保证取决于 Android 的始终开启 VPN / 阻断非 VPN 连接设置，不能把普通停止行为称为永久 kill switch。
