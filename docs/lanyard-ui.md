# 悬挂卡片连接控件

0.1.0-beta.5 / build 23 使用悬挂卡片连接控件。挂绳在窗口根层绘制，从屏幕最上沿连接到卡扣，独立于首页标题、状态栏留白和内容滚动。海洋和纯色首页使用同一个控件。

视觉与交互参考用户提供的 [React Bits Lanyard](https://reactbits.dev/components/lanyard) 示例。这里是独立编写的 Kotlin/Compose 实现，不包含 React、Three.js、上游 JavaScript、上游图片或 WebView；不宣称移植了完整三维物理引擎。

- 点按沿用连接、取消、断开或选择配置操作。开始建立连接即翻到背面，开始关闭即翻回；失败也回到正面。文字仍区分连接中、已建立和停止中，翻面本身不作为连通证明。
- 普通滑动不会触发开关；保持静止长按后才开始拖动，松手或取消回到原位。长按而不拖动也不会变成点按。拖动不会改变代理状态，位置与旋转有边界。
- 正面采用浅色缎面，背面采用深色反光面。Android 13+ 使用本地 AGSL 倒角法线、软箱反射及微纹；Android 10–12 使用保留微纹与反光的原生 Canvas 材质回退。着色参数只来自卡片姿态和 VPN 阶段，不接受订阅内容作为着色器代码。没有逐帧创建位图。
- 停止过程中和原业务状态禁用时不可操作。辅助功能仍提供按钮角色、当前状态和明确操作标签。
- 关闭系统动画、开启减少动效或进入后台时停止装饰动效。减少动效时拖拽仍不会被误认成点按。
- 卡片高度随大字体调整；支持 RTL。设置页的普通开关不变。
- 无新权限、依赖、运行时下载、追踪或持久化拖动轨迹。既有 VPN 和配置逻辑未修改。

针对性回归覆盖普通滑动与长按分离、松手/取消、点按一次、开关翻面时序、顶部锚点与端点跟随、实际着色器/回退选择、减少动效、禁用状态、大字体和 RTL。完整 VPN 夹具额外通过实际点按开启/关闭，并验证已连接时拖动不会断开。具体结果见 [验证记录](security-testing.md)。使用测试状态的截图另行标注，不将其作为真实订阅连通证明。
