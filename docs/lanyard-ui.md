# 悬挂卡片连接控件

0.1.0-beta.4 / build 22 将首页连接操作改为悬挂卡片，移除原按钮的圆角容器。海洋和纯色首页使用同一个控件。

视觉与交互参考用户提供的 [React Bits Lanyard](https://reactbits.dev/components/lanyard) 示例：短织带、金属环扣、卡片光泽、拖动倾斜与释放后的弹簧回弹。这里是独立编写的 Kotlin/Compose 实现，使用 Canvas 材质及 graphicsLayer 透视，不包含 React、Three.js、上游 JavaScript、上游图片或 WebView；不宣称移植了完整三维物理引擎。

- 点按沿用现有连接、取消连接、断开或选择配置操作。连接成功时翻到背面；状态文字由实际 VPN 状态提供。
- 拖动只改变卡片姿态，不执行连接操作；释放与取消回到原位。位置与旋转幅度均有边界。
- 停止过程中和原业务状态禁用时不可操作。辅助功能仍提供按钮角色、当前状态和明确操作标签。
- 关闭系统动画、开启减少动效或进入后台时停止装饰动效。减少动效时拖拽仍不会被误认成点按。
- 卡片高度随大字体调整；支持 RTL。设置页的普通开关不变。
- 无新权限、依赖、运行时下载、追踪或持久化拖动轨迹。既有 VPN 和配置逻辑未修改。

针对性回归覆盖拖动/松手/取消不触发 VPN、点按只提交一次、减少动效、禁用与停止状态、大字体和 RTL。具体运行结果见 [验证记录](security-testing.md)。截图若使用测试状态，须注明合成夹具，不将其作为真实节点连通证明。
