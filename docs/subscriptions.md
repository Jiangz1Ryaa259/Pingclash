# 订阅、HTTP providers 与延迟指标

以下描述当前源码。既有 `v0.1.0-beta.1` Release 的 APK 不会随源码变化而自动更新。

## 自定义 User-Agent 与配额

添加订阅时可填写 User-Agent；现有配置可在配置页修改，下次更新使用新值。默认 `Clash.Meta/PingClash-0.1.0`。为防请求头注入，接受 1–256 个可打印 ASCII 字符，拒绝换行和控制字符。服务商可能根据 UA 返回不同的节点或配置格式。

读取最终成功响应的 `subscription-userinfo` 头，显示已用、总配额、剩余量和有效期。有效期按本机时区显示；无响应头、无效字段和未知配额不会被解释为无限流量。数值限制在非负 64 位整数范围，上传和下载相加采取饱和计算。重复字段视为无效。刷新成功但缺少配额头会清除旧配额，避免把过期信息当成当前数据。

链接、UA、配额与提供源缓存均保存在应用私有、Android Keystore/AES-GCM 加密的配置文件中；不写入诊断报告或终端历史。配置导出不包含下载链接、请求头、UA 或配额，但仍含实际节点凭据，应仅在用户明确导出后妥善保管。

## HTTP providers 首版范围

- 支持 `type: http`，下载地址必须使用 HTTPS，保持系统证书及主机名验证。
- `proxy-providers` 支持 YAML `proxies` 列表。保留订阅策略组顺序、显式成员、嵌套选择、`use`、`include-all-providers`，以及受限 RE2 筛选。
- `rule-providers` 支持 `domain`、`ipcidr`、`classical`，格式为 YAML `payload` 或逐行 text。按原顺序将 `RULE-SET` 展开为现有路由引擎支持的规则，启用规则模式后生效。未知规则类型会明确失败。
- 支持单值列表形式的自定义请求头，包括 Authorization。禁止 Host、Cookie、连接控制等请求头。带自定义头的请求不能跨源重定向，避免凭据随跳转转发。
- `interval` 为 60–604800 秒，缺省 3600 秒。应用进程存活时每 60 秒检查到期项；不是精确闹钟。系统停止进程或进入 Doze 时可能延后，下次运行后补查，不为此增加保活权限。
- 缓存与原始定义保存在加密配置中，忽略配置自带的 `path`，不按订阅指定路径读写文件。
- 一轮更新必须全部下载并完成解析后才提交。出错保留上一份配置与缓存，显示来源的固定序号、类型和错误类别；这些提示不含 URL、请求头或原始异常。序号可在配置页与对应来源状态对照。
- VPN 运行时可刷新缓存，已有出站与规则继续使用原快照。内容变更会提示“重新连接后生效”；下次建立 VPN 时应用完整缓存更新。不会在会话中途悄悄替换代理路径。

当前限制：共最多 16 个来源，500 个节点、64 个策略组和 2000 条展开规则。单次响应最大 2 MiB，来源正文合计最大 2 MiB，下载阶段总预算 60 秒；完整加密配置仍受 3 MiB 存储预算限制。声明 `size-limit` 时还会检查该限制。过大配置会明确拒绝。

尚不支持 file/inline 提供源、MRS、任意 provider override、经指定代理组下载、跨来源重名节点，以及超出现有规则模型的规则。来源级 `health-check` 元数据不启动独立的全局健康检查服务；自动策略组继续使用原生 Mihomo 的组健康检查。不会把上述情况宣称为完整 Mihomo 配置兼容。YAML 别名等原有解析限制仍适用。

## TCP 与 URL 延迟

代理页的普通闪电测试继续使用原生 Mihomo URLTest。更多菜单提供独立 TCP 批量检测，节点卡片也可点击 TCP 指标单独检测。

TCP 测试绑定当前非 VPN 底层网络，仅建立节点入口端口的 TCP 连接并关闭，不发送代理认证、TLS 或 HTTP 内容。数字 IP 直接连接；域名先解析，显示时间不含 DNS 耗时。批次并发沿用设置，最大 16，支持取消，约每 100 毫秒批量更新 UI。网络变化时结果失效。

Hysteria2、TUIC 和策略组不适用 TCP 入口检测。TCP 成功只说明该端口可建立连接，不证明代理认证、服务器身份或完整链路可用。TCP 可达而 URL 失败，应继续查看代理通道诊断；TCP 失败也不能单凭一次结果断言运营商拦截。

二维码扫描及图片识别继续暂缓，普通文本框粘贴仍可使用。
