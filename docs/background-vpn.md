# 后台、网络切换与系统 VPN

仪表盘会保留最近任务卡片；Android 13 及以上禁用卡片快照。终端不显示为独立最近任务，退到后台会关闭 shell。VPN 服务独立于界面，移除仪表盘卡片不会替代“断开连接”。下拉通知提供服务状态、速度和断开操作。

“网络与连接 → 自动重连”默认开启。底层 Wi-Fi/蜂窝网络变化后，停止旧出站、保留原 TUN，等系统为应用选择可用的非 VPN 网络再重建内核会话；不任意枚举网络绕过其他 VPN。已有 TCP/QUIC 会话可能中断，应用需重新发起请求。用户主动断开、撤销 VPN 授权或配置校验失败后，不自动恢复。

前台服务被系统回收时，Android 可以按 sticky 服务语义重建；仅在本机仍有连接意图、已获得 VPN 授权且开启自动重连时接受重建。没有开机广播、自行授予 VPN 权限、精确闹钟或额外保活权限。系统强行停止应用和厂商后台策略不保证会触发重建。

## 系统设置

1. 在应用“设置 → 控制”打开系统 VPN 设置，进入 PingClash 的选项。
2. 如需系统自动维持 VPN，开启“始终开启的 VPN”。Android 的设置名称可能略有不同。
3. 如需 VPN 暂停、进程重建或启动失败时阻断流量，开启“阻止未使用 VPN 的连接 / 锁定模式”。请确认应用分流设置符合预期；被排除应用可能因此断网。
4. 常驻通知未显示时，检查应用“VPN 通知设置”的通知权限及通知渠道。Android 13+ 拒绝通知权限不等于前台服务没有运行。
5. 若系统仍清理 VPN，可检查系统电池管理中的后台运行或无限制选项。入口和实际效果由系统决定；应用不会自动豁免自身。

普通 VPN 模式中，应用进程被终止或系统撤销 VPN 后，系统可能恢复普通网络。TUN 在本应用处理网络切换时保留，不等于对所有系统终止情形提供永久断网保证。

当前已验证的设备与版本记录在 [README](../README.md) 和 [验证记录](security-testing.md)。模拟器不能代表每种 OEM ROM；报告问题只需系统版本、机型和固定错误类别，不要附设备编号、订阅或凭据。
